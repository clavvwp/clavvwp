## About

I'm Clavin, a self-taught web developer and UI designer from Indonesia. I like building websites that feel designed rather than assembled: clear layout, careful typography, and motion that has a reason to exist.

Most of what I make is personal and community work. That includes portfolios, organization sites, and a wedding organizer site, all built with a focus on how it looks and how it feels to scroll through.

Outside of code I play games, listen to music, and drink far too much coffee.
