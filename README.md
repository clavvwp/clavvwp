<br/>

I'm **Clavin**, a self-taught web developer and UI designer from Indonesia. I like building websites that feel designed instead of assembled: a clear layout, careful typography, and motion that has a reason to exist.

Most of my work is personal and community projects: portfolios, organization sites, and a wedding organizer website. Each one starts as a design problem before it becomes code.

> *"A good interface doesn't ask to be understood. It just works, and it looks like it was always meant to."*
